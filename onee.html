Windows SHOTCUT KEYS

Ctrl + C: Copy selected item.
Ctrl + X: Cut selected item.
Ctrl + V: Paste copied or cut item.
Ctrl + Z: Undo last action.
Ctrl + Y: Redo last undone action.
Ctrl + A: Select all items in a window.
Ctrl + S: Save current document or file.
Ctrl + P: Print current document or webpage.
Alt + F4: Close the current window or application.
Alt + Tab: Switch between open applications.
Windows Key + D: Show or hide the desktop.
Windows Key + E: Open File Explorer.
Windows Key + L: Lock your computer.
Windows Key + R: Open the Run dialog box.

Navigation & File Management:

Ctrl + F: Find in current window or document.
Ctrl + N: Open a new window or document.
Ctrl + O: Open an existing document or file.
F2: Rename the selected item.
F3: Open search feature in active window.
F5: Refresh the current window.
Shift + Delete: Delete selected item permanently.
Ctrl + Shift + Esc: Open Task Manager.
Ctrl + Left/Right Arrow: Move cursor to the beginning of the previous/next word.
Ctrl + Up/Down Arrow: Move cursor to the beginning of the previous/next paragraph.
Windows Key + Left/Right Arrow: Snap window to the left or right side of the screen.
Windows Key + Up Arrow: Maximize the active window.
Windows Key + Down Arrow: Minimize the active window.

Other useful shortcuts:

Windows Key + I: Open Settings.
Windows Key + A: Open Action Center.
Windows Key + S: Open Search.
Windows Key + Tab: Open Task View.
Windows Key + , (Comma): Temporarily peek at the desktop.
Ctrl + Shift + Esc: Open Task Manager.
Ctrl + Esc: Open Start Menu.
Windows Key + X: Open the Quick Link menu (Power User menu).
Windows Key + Print Screen: Take a screenshot and save it to Pictures folder.
